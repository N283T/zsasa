# zsasa logo assets

Every file is an SVG with its lettering converted to outlines, so no font is needed to display it.

| File | Use |
| --- | --- |
| `logo-on-light.svg`, `logo-on-dark.svg`, `logo-on-accent.svg` | Primary logo, for a light, a dark and an orange (`#f7a41d`) background |
| `logo-corners-on-*.svg` | The logo with corner marks, for titles and headers |
| `logo-frame-on-*.svg` | The logo in a frame, for use as a badge or sign-off |
| `icon-accent.svg`, `icon-dark.svg`, `icon-light.svg` | Square icon |

The logos have a transparent background: pick the file named after the background it will sit on.
