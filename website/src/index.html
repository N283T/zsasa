// 02 · Method

What gets measured.

Inflate every atom by the radius of a water-sized probe, 1.4 Å. The part of each inflated sphere that no neighbour covers is where solvent can reach. Shrake–Rupley estimates that area by testing points on each sphere.

The figure runs the same test live, on one plane through ubiquitin. Drag the ruler to move the plane.

// 03 · Throughput

Faster, in a fraction of the memory.

Whole AlphaFold proteomes, timed end to end: parsing, SASA and output. Exact f64 and f32 modes target matched Shrake–Rupley outputs; bitmask modes are a throughput-oriented approximation with a validated envelope.

// 04 · Capabilities

Built for whole datasets.

The same engine handles one structure, a proteome directory, or an MD trajectory.

Guides →
Algorithms

Shrake–⁠Rupley and Lee–⁠Richards

Shrake–Rupley is fast and recommended; Lee–Richards is the precise alternative. Both run in f64 or f32.

Formats

mmCIF, PDB, JSON, XTC, DCD

Structure files in, JSON or CSV out. Trajectories with automatic unit conversion.

Radii

CCD-aware classification

Hybridization-based radii for any chemical component, plus ProtOr, NACCESS, OONS and custom TOML tables.

Analysis

Per-residue, RSA, polarity

Residue aggregation, relative accessibility and polar / nonpolar partitioning without extra tooling.

Scale

Batch and trajectory native

Directory batch processing and streaming MD analysis are subcommands, not shell loops.

Platforms

Linux, macOS, Windows

A CLI binary, a Python package on PyPI, and a Zig library with interactive autodoc.
